# graduate-outcomes searches the web for sourcing, breaking the collection's no-external-dependency convention

Every other skill in this collection is a pure prompt spec with no external dependency — `refine-for-web` asks for content to be pasted rather than fetching it, on the assumption that fetch/search may not be available in the host tool. `graduate-outcomes` needs current, sourced career and salary data to avoid fabricating stats, and that data usually isn't present in course source copy, so it actively searches the web (HESA/Discover Uni, Prospects.ac.uk, LMI For All, professional bodies) when the runtime supports it. We accepted the portability trade-off — accuracy for outcomes claims matters more than guaranteed uniform behaviour across every install target — but kept the skill usable where search is unavailable: it falls back to `[INFERRED]`-flagged generic role/sector content rather than failing outright or fabricating figures.
