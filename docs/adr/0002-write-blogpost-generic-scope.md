# write-blogpost is the collection's first generic (non-HE) skill

Every existing skill in this repo is scoped to university web content for prospective students/researchers, and `CONTEXT.md`/`README.md` frame the whole collection that way. `write-blogpost` was requested as a general-purpose blog-writing skill, not tied to any institution or audience. Rather than starting a separate repo for one skill, we added it here as a deliberate exception — the portability and tooling conventions (Agent Skills standard, `install.sh`, plugin manifest, `agents/openai.yaml`) are all reusable regardless of domain, and a second repo for a single skill isn't worth the setup overhead. The trade-off: the collection's "HE only" framing is no longer strictly true. It still cross-references sibling skills (`meta-descriptions`, `geo-audit`) where their underlying principles apply generically, worded as "from this collection, if available" per the existing portability convention.
